# Karang Bay

**Karang Bay** is a complete 2D top-down open-world crime game that plays
offline in a desktop browser from its own files — no downloads, no network,
no assets: every street, sprite and sound is generated by the code in this
repository. It is our entry to the make.fun bounty
[gta6-01 — "Make GTA 6"](https://make.fun/bounty/gta6-01).

Welcome to Karang Bay, a harbour city on a coral bay. You are **Raka**, newly
arrived with $120 and a name that is already dirty. **Mara** the fixer offers
work, **Bara** runs the old market with his crew, **Dodi** keeps every engine
in the bay running, and **Inspector Sinta** watches it all from the GARUDA-1
helicopter. Eight jobs stand between Raka and a bay of his own.

## The city

Five districts on one continuous map, wrapped around a real coastline:

- **Pelabuhan** — the working port: container rows, cranes, docks, and two
  ships riding at anchor in the sea to the east.
- **Pasar Lama** — the old market: awnings, shop signs, Bara's turf.
- **Kota Tua** — the old town grid and its minimarket.
- **Bukit Hijau** — the green hills, quiet streets, the finale's ground.
- **Pantai Karang** — the beach strip along the sand and the waterline.

## What you can do

- Walk and drive anywhere: steal any car, drift it on the handbrake, leave
  skid marks and tire smoke, wreck it, ditch it.
- Live traffic that follows the road grid, stops at red lights and queues
  behind each other; pedestrians who stroll the sidewalks and flee crime.
- A full wanted system, 0–5 stars: foot officers, patrol cars with flashing
  light bars, and from 3 stars the GARUDA-1 helicopter with a searchlight.
  Break line of sight to cool off, repaint at Dodi's Pay-n-Spray, or lay low
  at the safehouse.
- Combat: fists, a purchasable pistol with magazines and reloads, Bara's
  rival crew, exploding barrels with chain reactions, cash/ammo/health
  pickups.
- **8 sequential missions** with named-character dialog: a package run, a
  debt collection, a timed taxi dash to the docks, a port investigation, a
  checkpoint race around the bay, a minimarket robbery and escape, an
  escort across town, and a night finale under the searchlight.
- Working shops: Gun Shop, Pay-n-Spray, Klinik, Safehouse.
- A day/night cycle with street lights and neon after dark, a live minimap,
  procedural WebAudio (engine, sirens, gunshots, a music loop), and
  localStorage saves — autosave after every mission, manual save at the
  safehouse.

## Controls

| Input | Action |
| --- | --- |
| WASD / arrow keys | Walk / drive |
| Shift | Run |
| E | Enter or leave a car, talk, use a shop, save at the safehouse |
| Mouse + left click | Aim; punch or shoot |
| Space | Handbrake |
| R | Reload |
| M | Mute |
| Esc | Pause |

## Run it

Serve the `game/` folder with any static server — or use the kit's
`serve.ts` — and open `game/index.html` in a desktop browser. Everything
runs locally; the game makes no network requests.

Deterministic screenshot staging for review lives in `shots.json`
(`?shot=chase|street|night|title&seed=1`).
